# Module 05: Practice System — 42-Day Mastery Program

> **Learning Objective:** Build a consistent, structured practice habit that takes you from beginner to expert prompt engineer through daily tasks, weekly challenges, real-world projects, and a shareable portfolio.

---

## Section 1: How This System Works

### Overview Diagram

```
Daily Tasks (15 min) → Weekly Challenges (1-2 hrs) → Projects (3-5 hrs) → Portfolio
       │                        │                          │                   │
       ▼                        ▼                          ▼                   ▼
  Build Habit             Apply Skills             Real Deliverables      Job-Ready

  Day 1–42               Week 1–6                  6 Projects             GitHub
  3 prompts/day          1 challenge/week           3 Levels               Showcase
  Score yourself         Produce artifact           Beginner → Advanced    Client-ready
```

**How it works:**

1. **Daily Tasks (15 min)** — Each day has a theme and 3 prompts to write. These build muscle memory. Do them even on busy days.
2. **Weekly Challenges (1–2 hrs)** — End-of-week deeper exercises that synthesize the week's skills into one deliverable.
3. **Projects (3–5 hrs each)** — 9 real-world projects across 3 difficulty levels. These become your portfolio pieces.
4. **Portfolio** — Everything you build gets documented and published to GitHub. This is your proof of skill.

## Section 2: Complete 42-Day Daily Program

### ━━━━━━━━━━━━━━━━━━━━━━━━━━━━
### WEEK 1: Foundations & Exploration
### ━━━━━━━━━━━━━━━━━━━━━━━━━━━━

**Day 1 — Your First Prompts** | ⭐ Beginner
- **Focus:** Understanding input/output basics
- **Prompt 1:** Ask ChatGPT to explain a topic you know well. Note where it's right/wrong.
- **Prompt 2:** Ask the same question 3 different ways. Compare the outputs.
- **Prompt 3:** Ask it to explain the same topic to: (a) a 10-year-old, (b) a PhD.
- **Expected Outcome:** Understand that prompt phrasing dramatically changes output.

---

**Day 2 — Specificity Training** | ⭐ Beginner
- **Focus:** Learning that vague prompts give vague results
- **Prompt 1:** Write a vague prompt. Then rewrite it with 5x more specificity. Compare.
- **Prompt 2:** Ask for a "list of ideas" → Then ask for "10 specific, actionable ideas for [exact context]"
- **Prompt 3:** Request an email. Then add: tone, length, audience, goal. Compare both versions.
- **Expected Outcome:** Learn that every added detail improves output quality.

---

**Day 3 — Format Control** | ⭐ Beginner
- **Focus:** Controlling how information is presented
- **Prompt 1:** Get the same information as: plain text, bullet points, table, numbered list.
- **Prompt 2:** Ask for output in JSON format. Then in Markdown. Then as a CSV.
- **Prompt 3:** Request a 50-word summary, then a 200-word version, then a 500-word version.
- **Expected Outcome:** Understand you have full control over output format.

---

**Day 4 — Tone and Voice** | ⭐ Beginner
- **Focus:** Adjusting communication style
- **Prompt 1:** Write the same message in 5 tones: formal, casual, funny, urgent, empathetic.
- **Prompt 2:** Ask it to write like a specific professional (lawyer, doctor, marketer).
- **Prompt 3:** Have it match YOUR writing style — paste a sample of your writing first.
- **Expected Outcome:** Ability to dial in tone precisely for any audience.

---

**Day 5 — Asking for Revisions** | ⭐ Beginner
- **Focus:** Iterative improvement through follow-up prompts
- **Prompt 1:** Generate a paragraph. Then: "Make it shorter." Then "Make it more persuasive." Then "Add a statistic."
- **Prompt 2:** Get a piece of writing, then ask: "What would make this better?" Then implement.
- **Prompt 3:** Request output → critique it yourself → ask for a specific fix.
- **Expected Outcome:** Learn to treat AI as a collaborative editing partner, not a one-shot machine.

---

**Day 6 — Tool Exploration: ChatGPT** | ⭐ Beginner
- **Focus:** Learning ChatGPT-specific features
- **Prompt 1:** Use Code Interpreter — upload a simple spreadsheet and ask for analysis.
- **Prompt 2:** Ask ChatGPT to generate an image with DALL-E 3 from a detailed description.
- **Prompt 3:** Enable browsing and ask for something that requires current information.
- **Expected Outcome:** Discover ChatGPT's unique capabilities beyond basic text generation.

---

**Day 7 — Tool Exploration: Claude & Gemini** | ⭐ Beginner
- **Focus:** Comparing tools side-by-side
- **Prompt 1:** Send the same creative writing prompt to Claude and ChatGPT. Document differences.
- **Prompt 2:** Use Gemini with search grounding to research a current event. Check citations.
- **Prompt 3:** Take Claude's best response and ask ChatGPT to improve it. Note what changes.
- **Expected Outcome:** Develop your own opinion about when to use each tool.

### WEEK 2: Building Prompt Structure
### ━━━━━━━━━━━━━━━━━━━━━━━━━━━━

**Day 8 — Context Setting** | ⭐⭐ Beginner
- **Focus:** Providing background information before your request
- **Prompt 1:** Write a prompt with zero context. Then write the same with full background. Compare.
- **Prompt 2:** Set up context with: who you are, what you're working on, what you need.
- **Prompt 3:** Include a "situation → complication → question" structure in your prompt.
- **Expected Outcome:** Learn that context upfront prevents unnecessary back-and-forth.

---

**Day 9 — Constraints and Guardrails** | ⭐⭐ Beginner
- **Focus:** Using constraints to sharpen outputs
- **Prompt 1:** Add word limits, forbidden words, and required inclusions to a writing prompt.
- **Prompt 2:** Ask for a list with exactly 7 items, no repetition, each item under 10 words.
- **Prompt 3:** Request content that must include 3 statistics, 1 example, and a CTA.
- **Expected Outcome:** Constraints produce more usable, focused outputs.

---

**Day 10 — Examples as Anchors** | ⭐⭐ Beginner
- **Focus:** Using few-shot examples to guide output
- **Prompt 1:** Show 1 example, then ask for 5 more in the same style.
- **Prompt 2:** Give 3 input-output pairs, then test on a new input (few-shot learning).
- **Prompt 3:** Paste an existing document and say "Write something similar for [new topic]."
- **Expected Outcome:** Understand that examples are the most powerful guide for output style.

---

**Day 11 — The RISEN Framework** | ⭐⭐ Beginner
- **Focus:** Applying a structured prompt framework
- **RISEN: Role, Instructions, Steps, End Goal, Narrowing**
- **Prompt 1:** Write a prompt using all 5 RISEN components for a task at work.
- **Prompt 2:** Take a previous weak prompt and rewrite it using RISEN. Compare outputs.
- **Prompt 3:** Use RISEN to ask for a marketing plan for a product you know.
- **Expected Outcome:** A go-to framework for professional-quality prompts.

---

**Day 12 — The CARE Framework** | ⭐⭐ Beginner
- **Focus:** CARE: Context, Action, Result, Example
- **Prompt 1:** Use CARE to write a prompt for customer email support.
- **Prompt 2:** Use CARE to create a job description for a role you're hiring.
- **Prompt 3:** Use CARE for a social media caption request.
- **Expected Outcome:** Second framework in your toolkit. Know when to use CARE vs. RISEN.

---

**Day 13 — Output Parsing Practice** | ⭐⭐ Beginner
- **Focus:** Getting structured outputs for downstream use
- **Prompt 1:** Ask for a product review summary in JSON: {pros, cons, rating, summary}
- **Prompt 2:** Request a 5-row CSV of fictional employee data with specific columns.
- **Prompt 3:** Ask for a Markdown-formatted article with H2/H3 headers, bold key terms, and a table.
- **Expected Outcome:** Ability to generate AI outputs that can feed into other systems.

---

**Day 14 — Week 1–2 Review** | ⭐⭐ Beginner
- **Focus:** Consolidate and self-assess
- **Prompt 1:** Write what you consider your best prompt from the past 2 weeks. Improve it further.
- **Prompt 2:** Ask ChatGPT to evaluate one of your prompts and suggest improvements.
- **Prompt 3:** Write a prompt explaining "what you've learned so far about prompt engineering" and use the output to create a personal cheat sheet.
- **Expected Outcome:** Clear personal reference guide of Week 1–2 learnings.

### WEEK 3: Intermediate Techniques
### ━━━━━━━━━━━━━━━━━━━━━━━━━━━━

**Day 15 — Role Prompting Basics** | ⭐⭐⭐ Intermediate
- **Focus:** Assigning professional roles to improve output quality
- **Prompt 1:** "Act as a [role]" → try 5 different roles for the same request.
- **Prompt 2:** Give the AI a detailed professional bio as its persona. Test if output quality changes.
- **Prompt 3:** Stack two roles: "You are both a lawyer and an entrepreneur. Advise me on..."
- **Expected Outcome:** Learn how role assignment unlocks domain-specific depth.

---

**Day 16 — Chain-of-Thought Prompting** | ⭐⭐⭐ Intermediate
- **Focus:** Getting AI to reason step-by-step
- **Prompt 1:** Add "Think step by step" to a math or logic problem. Compare with and without.
- **Prompt 2:** Ask: "Before answering, list all the factors you need to consider. Then answer."
- **Prompt 3:** Use CoT for a strategic decision: "Walk through your reasoning, then give your recommendation."
- **Expected Outcome:** Understand that revealing reasoning improves accuracy and trustworthiness.

---

**Day 17 — Self-Critique Loops** | ⭐⭐⭐ Intermediate
- **Focus:** Using AI to evaluate and improve its own outputs
- **Prompt 1:** Get a response → Ask: "Rate this response 1-10 and explain weaknesses." → Ask for improvement.
- **Prompt 2:** Generate a business plan → Ask: "Devil's advocate: what could go wrong with this plan?"
- **Prompt 3:** Write an argument → Ask: "Write the strongest counterargument to this position."
- **Expected Outcome:** Learn to use self-critique to get dramatically better final outputs.

---

**Day 18 — Persona and Audience Control** | ⭐⭐⭐ Intermediate
- **Focus:** Writing for specific readers
- **Prompt 1:** Write the same article introduction for: investor, customer, employee, journalist.
- **Prompt 2:** Adjust the same technical explanation for: CEO, engineer, intern, general public.
- **Prompt 3:** Create 3 versions of the same marketing message for different psychographic profiles.
- **Expected Outcome:** Skill to tailor any content to any specific audience with precision.

---

**Day 19 — Multi-Step Prompt Chains** | ⭐⭐⭐ Intermediate
- **Focus:** Linking prompts sequentially to build complex outputs
- **Prompt 1:** Step 1: outline → Step 2: write section 1 → Step 3: write section 2 → Step 4: conclusion.
- **Prompt 2:** Step 1: research brief → Step 2: SWOT analysis → Step 3: strategy recommendation.
- **Prompt 3:** Step 1: customer persona → Step 2: value proposition → Step 3: ad copy for that persona.
- **Expected Outcome:** Ability to break large tasks into reliable, chainable prompt workflows.

---

**Day 20 — Handling Ambiguity** | ⭐⭐⭐ Intermediate
- **Focus:** Teaching AI to ask for clarification rather than assume
- **Prompt 1:** "Before you answer, ask me the 3 questions you most need answered to do this well."
- **Prompt 2:** Give an intentionally vague request. Ask AI to state its assumptions before proceeding.
- **Prompt 3:** Ask: "What additional information would significantly improve your response here?"
- **Expected Outcome:** Collaborative, assumption-aware prompting that reduces output errors.

---

**Day 21 — Comparative Analysis** | ⭐⭐⭐ Intermediate
- **Focus:** Using AI for structured evaluation and comparison
- **Prompt 1:** Compare 3 marketing strategies using a structured criteria matrix.
- **Prompt 2:** Ask AI to compare two job offers using weighted scoring on 6 criteria.
- **Prompt 3:** Evaluate 3 competing products with a pros/cons/verdict table.
- **Expected Outcome:** Structured decision-making frameworks generated on demand.

## Section 3: 6 Weekly Challenges

---

### Challenge 1: Prompt Improvement Challenge (End of Week 1)

**Name:** The Rewrite Gauntlet

**Description:**
Take 5 poorly-written prompts (provided below or from your own experience) and transform each one into an expertly crafted version. Then test both versions and document the quality difference.

**Weak Prompts to Improve:**
1. "Write me a blog post"
2. "Help with my resume"
3. "Explain machine learning"
4. "Make a marketing plan"
5. "Write an email to my boss"

**Requirements:**
- Produce 5 "before" prompts and 5 improved "after" prompts
- Run all 10 through an AI tool
- Write a one-paragraph analysis for each comparing the outputs
- Create a "prompt improvement checklist" based on what you learned

**Evaluation Criteria:**
- Specificity improvement (1-10)
- Output quality improvement (1-10)
- Insight quality of analysis (1-10)

**Time Estimate:** 90 minutes

**Deliverable Format:** Markdown document with before/after pairs, outputs, and analysis

---

### Challenge 2: Role-Play Marathon (End of Week 2)

**Name:** The 10-Role Sprint

**Description:**
Assign 10 different professional roles to the AI and use each to complete a distinct task. Document how the role assignment changed the output.

**10 Roles to Test:**
1. Venture capitalist evaluating a startup pitch
2. Harvard professor explaining a concept
3. Award-winning copywriter writing an ad
4. Navy SEAL planning a complex operation (metaphorically, for project planning)
5. Therapist helping someone process a career decision
6. CFO reviewing a budget request
